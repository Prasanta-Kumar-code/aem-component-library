# Text Component

## Overview
Core Text Component v2 extension with rich text authoring and style-system support.

## Features
- Core Component inheritance
- Rich Text Editor and style policies
- Accessible semantic text output

## Dialog Fields
The inherited Core Text dialog provides rich text, links, and styles. Configure permitted styles through the template policy.

## Author Guide
Insert Text, format content with the toolbar, and select an approved style from the Styles menu.

## Screenshots
Add author and published screenshots to `docs/screenshots/text/`.

## Technical Design
Resource super type: `core/wcm/components/text/v2/text`. Rendering and sanitization remain owned by Core Components.
