# Button Component

## Overview
Core Button Component v2 extension for consistent links and calls to action.

## Features
- Label and link support
- New-tab target behavior
- Core style-system variants

## Dialog Fields
The inherited Core Button dialog provides text, link, accessibility label, and target controls. Configure visual variants as template policy styles.

## Author Guide
Enter a concise label, select an internal or external URL, and select the approved style variant.
