# Tabs Component

## Overview
Tabbed content with author-selected initial tab and keyboard-friendly buttons.

## Features
- Multifield tab items
- Active Tab field
- Progressive enhancement with scoped JavaScript
- Edit-mode placeholder

## Dialog Fields
Active Tab, Tab Title, and Tab Content.

## Author Guide
Add tabs in reading order and set Active Tab to a zero-based index.

## Screenshots
Add author and published screenshots to `docs/screenshots/tabs/`.

## Technical Design
`TabsModel` injects child resources and `aemcomponentlibrary.tabs` initializes selected panels.
